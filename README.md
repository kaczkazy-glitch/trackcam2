# TumbleCam
Camera2 10-bit HLG10 + GL 3D-LUT viewfinder, ML Kit flip tracker with Kalman prediction,
neon skeleton overlay, Zhiyun Smooth 5S BLE controller, iOS-style pro camera UI.

Build: push to GitHub, open Actions, download the TumbleCam-debug-apk artifact.
Local: `gradle assembleDebug` (Gradle 8.9, JDK 17).
